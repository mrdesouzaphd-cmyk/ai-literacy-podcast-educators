# Contributing to AI Literacy Podcast for Educators

Thank you for your interest in contributing!

## How to Contribute

### 1. Suggest a New Question
Open an **Issue** using the `new-question` label and fill in:
- The question text
- Four answer alternatives (A–D)
- The correct answer
- A scientific reference

### 2. Add or Improve a Script
- Fork this repository
- Edit or add a script in `/scripts/module-XX/`
- Follow the episode script format in existing files
- Submit a Pull Request

### 3. Upload Audio
- Record using [Google AI Studio → Generate Speech](https://aistudio.google.com/generate-speech)
- Name file as `epXX.mp3` (e.g., `ep01.mp3`)
- Place in the correct `/audio/module-XX/` folder
- Commit and push

### 4. Translate
We welcome Portuguese (PT-BR) translations of all scripts.
Create a `/scripts-pt/` folder mirroring the existing structure.

## Code of Conduct
- All content must be evidence-based with citations
- No promotion of specific commercial AI tools without balanced comparison
- Respectful, inclusive language at all times
