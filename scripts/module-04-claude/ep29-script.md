**[ANSWER]**

The correct answer is Option C.

Constitutional AI, introduced by Anthropic in 2022, is a method where the model is provided with a set of human-authored principles — the constitution. During training, the model generates responses, then critiques and revises those responses against the constitution, without requiring explicit human labeling for each revision.

This allows for more scalable, transparent alignment compared to pure Reinforcement Learning from Human Feedback, or RLHF.

For educators, this matters because Claude's behavior reflects a deliberate design philosophy: helpfulness, harmlessness, and honesty — often called the HHH framework. Understanding *how* these behaviors are instilled helps educators and students critically evaluate AI tool outputs.
