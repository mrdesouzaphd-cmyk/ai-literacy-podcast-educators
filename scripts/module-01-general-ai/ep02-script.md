How does Machine Learning relate to Artificial Intelligence?

---

**[ALTERNATIVES]**

Option A — Machine Learning and Artificial Intelligence are the same thing — just different names for the same technology.

Option B — Machine Learning is a subset of Artificial Intelligence, in which systems learn from data to improve performance without being explicitly programmed.

Option C — Artificial Intelligence is a subset of Machine Learning, meaning all AI systems use machine learning.

Option D — Machine Learning is an older technology that was replaced by Artificial Intelligence in the 2000s.

---

**[PAUSE CUE]**

Pause here. Think about it.

... three ... two ... one ...

---

**[ANSWER]**

The correct answer is Option B.

Artificial Intelligence is the broad field concerned with creating intelligent machines. Machine Learning is one approach *within* AI — it allows systems to learn from patterns in data rather than following hand-coded rules.

Think of it as nested circles: AI is the largest circle. Inside it is Machine Learning. And inside Machine Learning is Deep Learning — the technique that powers most modern AI tools like ChatGPT, Gemini, and Claude.

This distinction matters for educators because students often use these terms interchangeably, which leads to conceptual confusion when designing AI-integrated lessons.
