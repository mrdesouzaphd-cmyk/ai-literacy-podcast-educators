Question fifty-three.

What distinguishes Manus AI from a standard conversational chatbot like basic ChatGPT?

**[ALTERNATIVES]**

Option A — Manus only responds in Chinese and does not support other languages.

Option B — Manus is a passive question-answering system that waits for user input before performing any action.

Option C — Manus is an agentic AI system that can autonomously execute multi-step tasks — browsing the web, writing and running code, managing files, and completing complex workflows — with minimal human instruction per step.

Option D — Manus is a hardware device, not a software application.

**[PAUSE CUE]**

Pause here. What separates an agent from a chatbot?

... three ... two ... one ...

---

**[ANSWER]**

The correct answer is Option C.

Manus AI is classified as an **AI agent** — a system that does not just respond to prompts but autonomously *plans*, *executes*, and *iterates* on complex multi-step tasks. A user can give Manus a high-level goal — such as "research this topic and produce a formatted report" — and Manus will use tools like web browsers, code interpreters, and file systems to complete it.

This "agentic" paradigm represents a significant leap beyond conversational AI. The key concept is *tool use* and *autonomous planning* — the agent decides what sequence of actions to take to achieve a goal.

For educators, AI agents like Manus raise new questions about academic integrity, oversight, and the evolving definition of human-AI collaboration in learning environments.
