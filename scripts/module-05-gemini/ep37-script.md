Question thirty-seven.

What does it mean for an AI model like Gemini to be "natively multimodal"?

---

**[ALTERNATIVES]**

Option A — It means Gemini can speak multiple human languages simultaneously.

Option B — It means Gemini was trained to process and generate across multiple types of data — including text, images, audio, video, and code — within a single unified model architecture, rather than as separate specialized systems.

Option C — It means Gemini runs on multiple servers in multiple countries at the same time.

Option D — It means Gemini was trained by multiple research teams working in different modes or shifts.

**[PAUSE CUE]**

Pause. Which option best defines multimodality?

... three ... two ... one ...

---

**[ANSWER]**

The correct answer is Option B.

Native multimodality means that Gemini was designed from the beginning to process and generate text, images, audio, and video as a single integrated system — not as separate models bolted together.

This contrasts with systems where an image model and a language model are combined after training. Native multimodality allows for deeper cross-modal reasoning — for example, describing what is happening in a video while answering questions about it.

For educators, this is significant: Gemini Ultra was the first model to outperform human experts on MMLU — a benchmark spanning 57 academic subjects — when evaluated in its multimodal configuration.
