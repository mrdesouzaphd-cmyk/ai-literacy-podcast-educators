**[ANSWER]**

The correct answer is Option B.

A Large Language Model is an AI system trained on enormous datasets of text — books, websites, scientific papers, code, and more. It learns statistical patterns of language and uses those patterns to predict what text should come next in a sequence.

The "large" refers to two things: the size of the training data, and the number of parameters in the model. GPT-4, for example, is estimated to have over a trillion parameters — adjustable values learned during training.

LLMs don't "understand" language the way humans do — they model the *probability distribution* of language. This distinction is critical for educators teaching AI literacy, because it explains both the power and the limitations of these systems.
