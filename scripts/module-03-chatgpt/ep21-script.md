Question twenty-one.

What is the key functional difference between ChatGPT and a traditional search engine like Google?

---

**[ALTERNATIVES]**

Option A — ChatGPT is faster than Google and can process more searches per second.

Option B — ChatGPT retrieves and ranks existing web pages, while Google generates new text from scratch.

Option C — A search engine retrieves and links to existing documents on the web, while ChatGPT generates new text responses based on patterns learned during training — without browsing the web in real time by default.

Option D — There is no meaningful difference; both tools access the same information in the same way.

---

**[PAUSE CUE]**

Pause here. Consider carefully.

... three ... two ... one ...

---

**[ANSWER]**

The correct answer is Option C.

A search engine indexes and retrieves existing web pages, ranking them by relevance. ChatGPT, by default, does NOT browse the internet in real time. Instead, it generates responses based on patterns in the data it was trained on — which has a knowledge cutoff date.

This means ChatGPT can produce fluent, confident-sounding text that is outdated, inaccurate, or entirely fabricated — a phenomenon called "hallucination."

For educators, this distinction is essential: students must learn to verify ChatGPT outputs with primary and authoritative sources, not treat them as factual search results.

Some versions of ChatGPT do have a web browsing feature when enabled — but this is an add-on capability, not the core function of the model.
